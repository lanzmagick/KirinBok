# KirinBok 0.1.0 — Foundation

Date: 2026-11-26

## Added

- Initial Android application structure using Kotlin and Jetpack Compose.
- Material 3 navigation shell for Home, Anime, Manga, and Library.
- Separate Anime and Manga entry screens.
- External extension repository list with copyable addresses.
- Default Yuzono anime, Yuzono manga, and Keiyoushi manga repository addresses.
- Architecture, extension compatibility, and roadmap documentation.
- Single version source in builtsrc/version.kt.

## Not included yet

- Extension catalogue fetching/parsing, APK installation, or source loading.
- Online anime playback or the manga page reader.
- Offline downloads or a release APK.
